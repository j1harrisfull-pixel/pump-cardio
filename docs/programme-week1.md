# Programme – Week 1 (Mon 12 – Sun 18 Oct 2026) · v18, layout pc-v28

**pc-v28:** every session follows app-style-standard.md. Effort bands are single words with their RPE: **easy RPE 3–4 · steady RPE 5–6 · moderate RPE 7** (hard 8+ is not used). Strength and carry blocks have no guided timer: they show sets × reps and "Rest 60–90 s" (or 45–75 s), and the rest timer starts when you tick the last move of a round (the middle of the range, ±15 s). The former "Every 2:00 × 4" A-blocks and the Sat "every 75 s" stations are now supersets with the same moves, sets and reps; the Sat stations are split into B (swing, sumo deadlift) and C (suitcase carry, farmer's carry). Guided timers remain only for warm-ups, intervals, circuits, steady pieces, flows and cool-downs. Renamed: "Easy Run" → **Zone 2 Run**, "Backup · Easy Row + Mobility" → **Backup · Zone 2 Row + Mobility**, "Backup · Dumbbell Flow + Easy Run" → **Backup · Dumbbell Flow + Zone 2 Run**; logs saved under the old names keep them.


Rules: RPE 6–7, stop 2 reps short of failure, breathe out on every effort – never hold your breath, no maximal lifts, no heavy barbell work, no head-down positions.
**Stop and get checked** for a sudden or severe headache, any vision change, dizziness or feeling sick.

Every timer now includes switch time: **10 s GET READY** between mobility moves and sides, **15 s** between strength moves, **20 s** for equipment/floor changes, **5 s** before each row interval. The bar shows *Now X · Next Y* with a 3-2-1 beep. All times below include the switches and match the app.
Tempo e.g. 3011 = 3 s down · no pause · 1 s up · 1 s hold. Tap a rep pill to mark a set done; use −/+ if you got more or fewer reps.

### Pushing a one-day override
1. Add a session to `SESS` in `v12/app.js`, or reuse an existing id.
2. Set `OVR["YYYY-MM-DD"]="session-id"` in the `var OVR={}` map. This replaces only that date.
3. Bump `pc-vNN` in `v12/top.html`, `v9/sw.js` and `v9/test_sw.py`.
4. Rebuild with `cat v12/top.html v12/app.js > workout.html && cp workout.html v9/index.html`.
5. Run `test_v18.py`, `test_app.py`, `test_wt.py`, `test_v20.py` and `test_sw.py`.
6. Push `index.html` and `sw.js` in one commit to main, then check the live sw.js shows the new version.

## Effort and rowing guide (pc-v28 bands)
No pace or speed targets: go by effort and RPE. Rowing uses Concept2 PM5 format (time or metres, s/m stroke rate, damper 4–5, rest/light paddle).
| Effort | Run / walk | Row |
|---|---|---|
| easy RPE 3–4 | warm-up, cool-down and recovery walks, long walk | warm-up row, easy row, light paddle 18–20 s/m |
| steady RPE 5–6 | Zone 2 run, power walk intervals (backup) | Zone 2 row, steady row 20–22 s/m |
| moderate RPE 7 | run/walk interval work | row interval work 22–26 s/m |
| hard RPE 8+ | not used | not used |

On cardio days you can tap **Run instead (outdoor run)**. The run version keeps the same timings and effort words. The choice is saved per day, logged as "run instead", and you can switch back.
- **Wed main (row):** warm-up walk 4:00 → run/walk intervals 6 × (1:00 run, moderate pace, RPE 7 / 1:00 recovery walk) → Zone 2 run 4:00, steady pace, RPE 5–6.
- **Wed backup:** run/walk intervals 8 × (1:00 steady run / 1:00 recovery walk), steady pace, RPE 5–6.
- **Sat backup:** Zone 2 run 5:00 instead of the cool-down walk, steady pace, RPE 5–6. Sat main (KB + Carry) has no cardio block.
