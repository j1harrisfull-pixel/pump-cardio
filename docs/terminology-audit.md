# Terminology audit (pc-v23)

**pc-v23 change:** effort uses single words only: easy, steady, moderate, hard. There are no combined or hyphenated terms. "steady-hard" became **moderate** (RPE 7 row intervals). The Mon backup "Steady 24:00 row / Steady-state row" became **Easy 24:00 row**, because it was labelled steady but done at easy pace.


**pc-v22 change:** James wants no exact pacing. Every numeric pace or speed target (min/km, km/h, /500m splits, drag-factor numbers) and every distance derived from pace has been removed. Effort is now written as easy pace / steady pace / moderate pace plus RPE. The standard terms, s/m stroke rate and damper 4–5 stay. The v21 numbers below are crossed out for the record.

## Removed in v22 (no pace targets)
- ~~7:00–7:45/km (≈7.7–8.6 km/h)~~ → easy run (Zone 2), RPE 6
- ~~6:15–6:45/km (≈8.9–9.6 km/h)~~ → steady run, RPE 7
- ~~5–6.5 km/h walk speeds~~ → warm-up / power / recovery / cool-down walk
- ~~2:10–2:45/500m splits~~ → easy / steady / moderate pace, with the s/m stroke rate kept
- ~~drag factor ≈110–130~~ → damper 4–5 only
- ~~≈0.9 / 2.3–2.5 / 4.5–4.8 km~~ (derived from pace) → removed

All timings are unchanged.
